# AI Website Builder Pro
**By Rishabh Sharma — WordPress & Web Developer**

## Deploy kaise karein (5 steps):

### Step 1 — Anthropic API Key lo (FREE trial available)
- [console.anthropic.com](https://console.anthropic.com) pe jao
- API Keys → Create Key → Copy

### Step 2 — GitHub pe upload karo
- github.com → New repository → "website-builder"
- Sab files upload karo (index.html, api/generate.py, requirements.txt, vercel.json)

### Step 3 — Vercel pe deploy karo
- [vercel.com](https://vercel.com) → Import from GitHub
- Project select karo → Deploy

### Step 4 — Environment Variable add karo
- Vercel Dashboard → Settings → Environment Variables
- Name: `ANTHROPIC_API_KEY`
- Value: apni API key paste karo
- Redeploy karo

### Step 5 — Use karo!
- `yoursite.vercel.app` kholo
- Business details daalo
- "Build Website" dabao
- Claude AI har section uniquely likhega!
